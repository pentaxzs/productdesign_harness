# Evaluation Checklist

Critic Agent가 Prototype을 검증할 때 사용하는 체크리스트입니다.

---

## 요구사항 충족 (Requirement Coverage)

### Key Scenarios
- [ ] 사용자가 조건을 설정하여 카드를 검색하고 결과를 확인할 수 있다.
- [ ] 사용자가 AI에게 상황을 설명하고 추천 카드를 받을 수 있다.
- [ ] 사용자가 관심 카드 2~3개를 선택하여 비교할 수 있다.
- [ ] 사용자가 카드 상세 정보를 확인하고 발급 페이지로 이동할 수 있다.

### 검색 기능
- [ ] 카드 이름/키워드로 검색할 수 있다.
- [ ] 카드 종류(신용/체크)로 필터링할 수 있다.
- [ ] 혜택 카테고리로 필터링할 수 있다.
- [ ] 연회비 범위로 필터링할 수 있다.
- [ ] 카드사로 필터링할 수 있다.

### AI 추천 기능
- [ ] 사용자가 자연어로 자신의 상황을 입력할 수 있다.
- [ ] AI 추천 결과가 카드 목록으로 표시된다.
- [ ] 추천 이유가 함께 제공된다.
- [ ] 추천 결과에서 검색/필터로 전환할 수 있다.

### 비교 기능
- [ ] 카드를 비교 목록에 추가/제거할 수 있다.
- [ ] 선택한 카드들을 나란히 비교할 수 있다.
- [ ] 비교 항목이 동일한 기준으로 정렬되어 있다.

## UX 원칙 점검

| 원칙 | 점검 항목 | Pass/Fail |
|------|----------|-----------|
| 정보 계층 | 핵심 정보(카드명, 혜택, 연회비)가 먼저 보이는가? | |
| 최소 단계 | 검색 → 결과까지 불필요한 단계가 없는가? | |
| 신뢰감 | 정보가 정확하고 일관되게 표현되는가? | |
| 일관된 패턴 | 카드 정보가 모든 화면에서 동일 구조인가? | |
| 검색/AI 균형 | 검색과 추천이 자연스럽게 연결되는가? | |
| 상태 처리 | Empty/Error/Loading이 모두 존재하는가? | |
| 반응형 | Mobile/PC 모두 정상 동작하는가? | |
