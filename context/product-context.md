# Product Context

## Service Name
CardFit — 나에게 맞는 카드를 찾아주는 서비스

## Service Background (서비스 배경)
기존 카드 비교 사이트(카드고릴라 등)의 불편한 검색·비교 경험을 개선하려는 서비스.
수많은 카드 중에서 자신에게 맞는 카드를 찾기 어려운 문제를 해결한다.

## Product Vision
누구나 자신의 소비 패턴에 맞는 최적의 카드를 쉽고 빠르게 찾을 수 있는 웹 서비스.

## Target Users
- 첫 카드를 발급받으려는 사회초년생
- 기존 카드 혜택에 불만족하여 갈아타려는 직장인
- 특정 혜택(마일리지, 캐시백, 할인 등)을 극대화하고 싶은 소비자
- 폭넓은 타겟 — 카드를 사용하는 모든 사람

## Core Value Proposition
AI 맞춤 추천이 핵심 차별점.
사용자의 소비 패턴이나 상황을 입력하면 AI가 최적의 카드를 추천해주어,
기존 서비스 대비 더 정확하고 개인화된 카드 탐색 경험을 제공한다.

## Business Goal (비즈니스 목표)
- 수익 모델: 카드사 제휴/발급 리퍼럴 수수료
- 핵심 KPI: 카드 발급 신청 전환율, 월간 활성 사용자 수

## Platform & Constraints (플랫폼 & 제약 조건)
- 반응형 웹 (PC + Mobile)
- Mobile First 설계 (기준 너비: 375px), PC 확장 (기준 너비: 1440px)
- 터치 타겟 최소 44px
- 실제 API 없이 목업 데이터로 동작하는 Interactive Prototype

## Tone & Mood (톤 & 무드)
- 깔끔/미니멀 — 심플한 도구 느낌
- 불필요한 장식 없이 정보에 집중
- 신뢰감 있는 톤 유지 (금융 서비스이므로)

## Key Scenarios
1. 사용자가 조건을 설정하여 카드를 검색하고 결과를 확인한다.
2. 사용자가 AI에게 자신의 상황을 설명하고 추천 카드를 받는다.
3. 사용자가 관심 카드 2~3개를 선택하여 비교한다.
4. 사용자가 카드 상세 정보를 확인하고 발급 페이지로 이동한다.
