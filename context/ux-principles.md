# UX Principles

이 프로토타입에서 모든 Agent가 반드시 따라야 하는 UX 원칙입니다.

## 1. 명확한 정보 계층 (Clear Information Hierarchy)
- 가장 중요한 정보(카드 이름, 핵심 혜택, 연회비)가 먼저 보여야 한다.
- 부가 정보는 접기/펼치기 또는 상세 페이지에서 제공한다.
- 한 화면에 너무 많은 정보를 보여주지 않는다.

## 2. 최소 단계 (Minimum Steps)
- 사용자가 원하는 카드를 찾기까지의 단계를 최소화한다.
- 검색은 즉시 결과를 보여주는 방향으로 설계한다.
- 불필요한 회원가입이나 로그인 없이 핵심 기능을 사용할 수 있어야 한다.

## 3. 신뢰감 (Trust)
- 카드 정보는 정확하고 최신이라는 인상을 준다.
- 과장된 표현이나 광고성 문구를 지양한다.
- 비교 시 동일한 기준으로 정보를 제시한다.

## 4. 일관된 패턴 (Consistent Patterns)
- 동일한 유형의 정보는 동일한 방식으로 표현한다.
- 카드 리스트, 카드 상세, 비교 화면에서 정보 구조가 일관되어야 한다.
- Design System 컴포넌트를 우선 사용하고, 커스텀 UI를 최소화한다.

## 5. 탐색과 추천의 균형 (Search & AI Balance)
- 검색(능동적 탐색)과 AI 추천(수동적 발견)을 자연스럽게 연결한다.
- AI 추천은 강요하지 않고, 사용자가 선택할 수 있게 한다.
- AI 추천 결과에도 사용자가 필터를 추가로 적용할 수 있어야 한다.

## 6. 모든 상태를 고려 (Handle All States)
- Empty State: 검색 결과가 없을 때, 비교할 카드를 선택하지 않았을 때
- Error State: 네트워크 오류, 검색 실패
- Loading State: AI 추천 생성 중, 검색 결과 로딩 중
- 각 상태에서 사용자가 다음에 무엇을 해야 하는지 안내한다.

## 7. 반응형 우선 (Responsive First)
- Mobile에서 먼저 설계하고, PC로 확장한다.
- 터치 타겟은 최소 44px을 유지한다.
- PC에서는 공간을 활용하되, 정보 밀도를 적절히 조절한다.
