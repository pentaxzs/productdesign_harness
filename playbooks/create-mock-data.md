# Skill: 목업 데이터 생성

## 목적
실제 API 없이 프로토타입이 동작하도록 현실적인 목업 데이터를 생성한다.

## 사용하는 Agent
- Prototype Agent (주 사용)

## 절차

### 1. 엔티티 도출
`specs/screens.md`와 `specs/user-flow.md`를 읽고, 화면에 표시되는 **핵심 엔티티**를 찾는다.
대부분의 제품은 1~3개의 핵심 엔티티를 가진다.

- 목록 화면에 반복해서 나오는 것 → 주 엔티티
- 상세 화면에서 펼쳐지는 것 → 주 엔티티의 하위 필드
- 필터/카테고리로 쓰이는 것 → 분류 엔티티

### 2. 필드 정의
주 엔티티마다 아래 범주를 채운다. 화면에 필요한 것만 넣는다.

| 범주 | 설명 |
|------|------|
| 식별 | `id`, `name` |
| 분류 | 타입, 카테고리, 태그 — 필터에 쓰이는 값 |
| 핵심 지표 | 목록·비교 화면에서 나란히 보이는 숫자나 등급 |
| 상세 정보 | 상세 화면에서만 보이는 설명, 하위 목록 |
| 사회적 증거 | 평점, 리뷰 수, 사용자 수 (있는 경우) |
| 미디어 | 이미지 — 프로토타입에서는 `null` + placeholder |
| 액션 | 외부 링크나 다음 단계 (목업은 `"#"`) |

### 3. 수량과 다양성 규칙
- **최소 12개** 생성한다. 목록·필터·비교가 의미 있게 동작하려면 이 정도가 필요하다.
- 각 분류 값이 **최소 2개 이상**의 항목에 등장해야 한다.
- 숫자 필드는 **최솟값·최댓값·중간값**이 모두 존재하도록 분포시킨다. (0원 항목, 최고가 항목 포함)
- **필터를 조합하면 결과가 0건이 되는 경우**가 반드시 존재해야 한다 → Empty State 테스트용
- 극단값 항목을 1~2개 넣는다. (이름이 아주 긴 항목, 값이 없는 항목) → 레이아웃 깨짐 테스트용

### 4. 자동 생성 응답 (AI·추천 기능이 있는 경우)
입력에 따라 다른 결과를 보여주려면 **키워드 → 응답** 맵을 만든다.
`default` 키를 반드시 포함해 어떤 입력에도 응답이 나오게 한다.

```javascript
const responses = {
  "<키워드>": {
    summary: "<한 줄 요약>",
    reason: "<이 결과를 추천하는 근거>",
    resultIds: [1, 5, 8],
  },
  "default": { /* ... */ }
};
```

> UX 원칙 3(신뢰감)에 따라 `reason`을 반드시 포함한다. 자동 생성 결과에는 근거가 보여야 한다.

## Output
`prototype/js/data.js`에 작성

## 검증
- 주 엔티티가 12개 이상인가?
- 각 분류 값이 2개 이상의 항목에 등장하는가?
- 필터 조합으로 결과 0건을 만들 수 있는가? (Empty State)
- 모든 항목의 필수 필드가 채워져 있는가?
- 극단값 항목이 포함되어 있는가?

## 예시 (CardFit — 카드 추천 서비스)

> 아래는 형식 참고용입니다. 제품에 맞게 교체하세요.
> 전체 예시: `examples/cardfit/prototype/app.js`

```javascript
const cards = [
  {
    id: 1,
    name: "카드 이름",
    type: "credit",                  // 분류
    issuer: "카드사 이름",            // 분류
    annualFee: 15000,                // 핵심 지표
    image: null,                     // placeholder
    benefits: ["카페", "교통"],       // 분류 (다중)
    highlights: [                    // 상세 정보
      { category: "카페", description: "스타벅스 30% 할인", rate: "30%" },
    ],
    rating: 4.5,                     // 사회적 증거
    reviewCount: 1234,
    tags: ["인기", "캐시백"],
    detailUrl: "#",                  // 액션
  },
  // ... 11개 더
];
```

| 범주 | CardFit 적용 | 학습 앱이라면 |
|------|-------------|--------------|
| 주 엔티티 | 카드 12개 | 레슨/단어 12개 |
| 분류 | 카드사, 신용/체크, 혜택 | 레벨, 품사, 주제 |
| 핵심 지표 | 연회비, 적립률 | 정답률, 복습 주기 |
| 사회적 증거 | 평점, 리뷰 수 | 학습자 수, 완료율 |
