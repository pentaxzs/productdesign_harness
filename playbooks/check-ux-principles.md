# Skill: UX 원칙 위반 점검

## 목적
Prototype이 `context/ux-principles.md`의 7가지 원칙을 준수하는지 점검한다.

## 사용하는 Agent
- Critic Agent (주 사용)

## 점검 항목

### 1. 명확한 정보 계층
각 화면에서:
- 핵심 정보(카드명, 혜택, 연회비)가 시각적으로 가장 먼저 보이는가?
- 부가 정보가 적절히 숨겨져 있는가?
- 한 화면에 정보가 과하지 않은가?

### 2. 최소 단계
- 검색 시작부터 결과 확인까지 몇 단계인가? (목표: 2단계 이내)
- 불필요한 중간 화면이 존재하는가?
- 로그인/회원가입 없이 핵심 기능을 사용할 수 있는가?

### 3. 신뢰감
- 과장된 표현이나 광고성 문구가 있는가?
- 비교 시 동일한 기준으로 정보가 제시되는가?
- 정보 출처나 업데이트 날짜가 표시되는가?

### 4. 일관된 패턴
- 카드 정보가 모든 화면에서 동일한 구조로 표현되는가?
- 같은 액션이 다른 위치/스타일로 표현된 곳이 있는가?
- DS 컴포넌트가 일관되게 사용되었는가?

### 5. 탐색과 추천의 균형
- 검색에서 AI 추천으로 자연스럽게 전환할 수 있는가?
- AI 추천이 강제되지 않는가?
- AI 추천 결과에 추가 필터를 적용할 수 있는가?

### 6. 모든 상태를 고려
- Empty State가 존재하고 다음 행동을 안내하는가?
- Loading State가 자연스러운가?
- Error State가 복구 방법을 안내하는가?

### 7. 반응형 우선
- Mobile에서 모든 기능이 사용 가능한가?
- 터치 타겟이 44px 이상인가?
- 가로 스크롤이 발생하지 않는가?

## Output 형식
```markdown
## UX 원칙 점검

| 원칙 | 판정 | 위반 사항 |
|------|------|----------|
| 정보 계층 | Pass/Fail | [위반 내용] |
| 최소 단계 | Pass/Fail | [위반 내용] |
| ... | | |

### 위반 상세
1. **[원칙]** — [화면] — [위반 내용] — [심각도]
```
