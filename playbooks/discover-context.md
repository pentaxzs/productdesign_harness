# Playbook: Discovery (맥락 확보)

## 목적
기획을 시작하기 전에, 1-pager 수준의 핵심 맥락을 확보한다.
정보가 이미 있으면 확인만 하고, 빠진 것만 질문한다.

## 사용하는 Agent
- Planner Agent

## 전제
- `context/product-context.md`가 존재한다 (빈 템플릿이거나 부분적으로 채워져 있을 수 있다).
- 사용자의 자연어 요청이 있다.

## 필수 항목 (1-pager Checklist)

아래 7개 항목이 Product Context에 채워져 있어야 한다:

| # | 항목 | 설명 | 예시 질문 |
|---|------|------|-----------|
| 1 | **서비스 배경** | 왜 이 서비스를 만드는가? 어떤 문제를 해결하는가? | "이 서비스를 만들게 된 배경이나 해결하려는 문제가 뭔가요?" |
| 2 | **타겟 유저** | 누가 쓰는가? 1~3개 페르소나 | "주요 사용자는 누구인가요? 어떤 상황에서 이 서비스를 쓰게 되나요?" |
| 3 | **핵심 가치 제안** | 사용자에게 주는 핵심 가치가 무엇인가? | "이 서비스가 기존 대안 대비 어떤 점이 나은가요?" |
| 4 | **비즈니스 목표** | 서비스 제공자의 목표 (수익 모델, KPI 등) | "이 서비스의 비즈니스 모델이나 핵심 KPI는 뭔가요?" |
| 5 | **핵심 시나리오** | 사용자가 수행하는 주요 Task 3~5개 | "사용자가 이 서비스에서 하는 가장 중요한 행동 3~5가지는?" |
| 6 | **플랫폼 & 제약 조건** | 웹/앱, 반응형 여부, 기술 제약 | "PC/모바일 둘 다 지원하나요? 기술적 제약이 있나요?" |
| 7 | **톤 & 무드** | 서비스의 성격 (전문적, 친근한, 신뢰감 등) | "서비스의 분위기는 어떤 느낌이면 좋을까요?" |

## 절차

### 1. 기존 정보 점검
`context/product-context.md`를 읽고 위 7개 항목 중 이미 채워진 것을 확인한다.

### 2. Gap 분석
채워지지 않은 항목, 또는 너무 모호한 항목을 목록화한다.

### 3. 질문 생성
빠진 항목에 대해 질문을 만든다.

**질문 원칙:**
- 한 번에 묶어서 질문한다 (여러 번 왔다갔다 하지 않는다).
- 구체적으로 질문한다 ("좀 더 알려주세요" ✗ → "주요 사용자는 20대 사회초년생인가요, 아니면 다른 그룹도 있나요?" ✓)
- 이미 사용자가 준 정보에서 추론 가능한 것은 추론 후 확인만 받는다.
- 선택지를 제시하면 답하기 쉽다 (예: "수익 모델은 a) 카드사 제휴 수수료 b) 광고 c) 프리미엄 구독 중 어떤 방향인가요?")

### 4. 답변 반영
사용자의 답변을 `context/product-context.md`에 반영하여 업데이트한다.

### 5. 완료 확인
7개 항목이 모두 최소한의 수준으로 채워졌는지 확인한다.
- 완전하지 않아도 된다. 프로토타입에 필요한 수준이면 충분하다.
- 답변을 거부한 항목은 합리적 가정을 세우고 명시한다.

## Output
- 업데이트된 `context/product-context.md`
- 다음 단계(analyze-requirements)로 진행

## 예시: 질문 메시지

```
기획을 시작하기 전에 몇 가지 확인하고 싶습니다:

1. **서비스 배경**: 신용카드/체크카드 추천 서비스를 만드시려는 배경이 뭔가요?
   (예: 기존 카드 비교 사이트의 불편함 해소, 핀테크 앱의 한 기능 등)

2. **타겟 유저**: 주로 어떤 사용자를 대상으로 하시나요?
   a) 첫 카드 발급 (사회초년생)
   b) 기존 카드 갈아타기 (직장인)
   c) 특정 혜택 극대화 (소비 최적화)
   d) 모두 해당

3. **비즈니스 목표**: 수익 모델은 어떤 방향인가요?
   a) 카드사 제휴/리퍼럴 수수료
   b) 광고 수익
   c) 아직 미정
   
4. **톤 & 무드**: 어떤 느낌의 서비스면 좋을까요?
   a) 전문적/신뢰감 (금융 서비스 느낌)
   b) 친근/캐주얼 (토스 같은 느낌)
   c) 깔끔/미니멀

답변 주시면 바로 기획에 반영하겠습니다.
```
