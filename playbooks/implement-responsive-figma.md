# Playbook: Figma 반응형 표현

## 목적
Figma에서 반응형을 표현한다. Mobile(375px)과 Desktop(1440px) 프레임을 쌍으로 만들어 나란히 배치한다.

## 사용하는 Agent
- Wireframe Agent

## Figma에서 반응형 표현 방식

Figma는 CSS media query가 없으므로, **같은 화면을 두 개의 프레임으로 만들어** 반응형을 표현한다.

### 프레임 쌍 구조
```
[Mobile] 홈     ←→     [Desktop] 홈
  375px                   1440px
  단일 컬럼               멀티 컬럼
```

### Mobile → Desktop 변환 규칙

| 요소 | Mobile (375px) | Desktop (1440px) |
|------|---------------|-----------------|
| 콘텐츠 영역 | 풀 너비 (패딩 16px) | 최대 1200px 중앙 정렬 (패딩 120px) |
| 카드 그리드 | 1열 | 3열 (gap 24px) |
| 필터 | 수평 스크롤 태그 + "필터" 버튼 | 사이드바 패널 (너비 280px) |
| 비교 화면 | 세로 스택 또는 좌우 스와이프 힌트 | 가로 나란히 (2~3열) |
| 히어로 | 세로 배치 (텍스트 → 입력) | 가로 2컬럼 (텍스트 | 입력) |
| 네비게이션 | 로고 + 햄버거 아이콘 | 로고 + 텍스트 메뉴 링크 |
| 하단 CTA | 하단 고정 바 (풀 너비) | 콘텐츠 내 인라인 또는 우측 사이드 |
| 푸터 | 1열 세로 스택 | 3~4열 가로 |

### 간격 체계
| 구분 | Mobile | Desktop |
|------|--------|---------|
| 섹션 간 | 48px | 64px |
| 컴포넌트 간 | 16px | 24px |
| 컴포넌트 내부 | 8px | 12px |
| 페이지 좌우 패딩 | 16px | 120px (또는 중앙 정렬 1200px) |

### 터치 타겟 (Mobile)
- 모든 인터랙티브 요소 최소 높이: 44px
- 버튼 최소 크기: 44px × 44px
- Desktop에서는 36px까지 허용

## 절차

### 1. Mobile 프레임 먼저
- 375px 너비로 모든 요소를 단일 컬럼 배치
- Auto Layout vertical 사용
- 콘텐츠가 세로로 자연스럽게 흐르도록

### 2. Desktop 프레임은 Mobile 구조를 확장
- 같은 정보, 같은 순서, 다른 레이아웃
- 멀티 컬럼이 필요한 곳만 변경
- 불필요한 요소 추가/삭제 없음 (정보는 동일)

### 3. 프레임 나란히 배치
- Mobile (x: 960, y: Y)
- Desktop (x: 960 + 375 + 60 = 1395, y: Y) — 같은 y 좌표

## 검증
- Mobile과 Desktop이 같은 정보를 담고 있는가?
- 레이아웃 변환 규칙이 일관되게 적용되었는가?
- Mobile에서 터치 타겟 44px 이상인가?
- Desktop에서 콘텐츠가 1200px 이내인가?
