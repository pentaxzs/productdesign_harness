# User Flow

## Flow 1: 조건 검색으로 카드 찾기
**시작점**: 홈 화면
**끝점**: 카드 발급 페이지 이동 (외부 링크)

1. 사용자가 홈 화면에 진입한다 → 시스템이 Hero + 검색/AI 추천 진입점을 보여준다 → **홈**
2. 사용자가 카드 종류(신용/체크) 탭을 선택한다 → 탭 전환
3. 사용자가 혜택 카테고리를 선택한다 (캐시백, 마일리지, 할인 등) → 필터 설정
4. 사용자가 연회비 범위, 카드사 등 추가 조건을 설정한다 → 필터 설정
5. 사용자가 "카드 찾기" 버튼을 누른다 → **검색 결과 (Loading)**
6. 시스템이 검색 결과를 보여준다 → **검색 결과 (Default)**
   - 조건 A: 결과 0건 → **검색 결과 (Empty)**
   - 조건 B: 결과 있음 → 카드 리스트 표시
7. 사용자가 카드를 탭한다 → **카드 상세**
8. 사용자가 "발급 신청" 버튼을 누른다 → 외부 카드사 페이지로 이동

### Edge Cases
- 검색 결과 0건 → "조건에 맞는 카드가 없어요" + 조건 완화 제안 + 인기 카드 추천
- 네트워크 오류 → "검색 중 오류가 발생했어요" + 재시도 버튼

---

## Flow 2: AI 추천으로 카드 찾기
**시작점**: 홈 화면
**끝점**: 카드 발급 페이지 이동 (외부 링크)

1. 사용자가 홈 화면에서 AI 추천 영역을 확인한다 → **홈 (AI 추천 섹션)**
2. 사용자가 소비 패턴이나 상황을 텍스트로 입력한다
   - 예: "월 200만원 쓰는데 온라인 쇼핑이 많아요"
3. 사용자가 "추천받기" 버튼을 누른다 → **AI 추천 결과 (Loading)**
4. AI가 추천 카드 목록을 보여준다 → **AI 추천 결과 (Default)**
   - 조건 A: 추천 실패 → **AI 추천 결과 (Error)**
5. 사용자가 추천 카드를 탭한다 → **카드 상세**
6. 사용자가 "발급 신청" 버튼을 누른다 → 외부 카드사 페이지로 이동

### Edge Cases
- AI 추천 실패 → "추천을 생성하지 못했어요" + 재시도 / "직접 검색하기" 안내
- AI 응답 지연 → 로딩 애니메이션 + "맞춤 카드를 찾고 있어요..." + 취소 가능

---

## Flow 3: 카드 비교하기
**시작점**: 검색 결과 또는 AI 추천 결과
**끝점**: 카드 발급 페이지 이동 (외부 링크)

1. 사용자가 검색 결과/추천 결과에서 비교할 카드를 선택한다 (체크박스) → 하단에 비교 바 표시
2. 사용자가 "비교하기" 버튼을 누른다 → **카드 비교**
   - 조건 A: 1개만 선택 → "2개 이상 선택해주세요" 안내
   - 조건 B: 2~3개 선택 → 비교 화면 이동
3. 비교 화면에서 카드 혜택, 연회비, 조건을 나란히 비교한다 → **카드 비교 (Default)**
4. 사용자가 특정 카드의 "발급 신청"을 누른다 → 외부 카드사 페이지로 이동
5. 또는 카드를 탭하여 상세 확인 → **카드 상세**

### Edge Cases
- 비교에서 카드 제거 시 1개 남음 → "카드를 추가해주세요" 안내
- 비교 카드 최대 3개 제한 → 추가 선택 시 "최대 3개까지 비교할 수 있어요" 안내

---

## Flow 4: 카드 상세 확인
**시작점**: 검색 결과 / AI 추천 결과 / 비교 화면 / 홈 인기 카드
**끝점**: 발급 신청 (외부) 또는 뒤로가기

1. 사용자가 카드를 탭한다 → **카드 상세 (Loading)**
2. 시스템이 카드 상세 정보를 보여준다 → **카드 상세 (Default)**
3. 사용자가 혜택 상세를 펼쳐본다 (Accordion)
4. 사용자가 "발급 신청" 버튼을 누른다 → 외부 카드사 페이지로 이동
5. 또는 "비교에 추가" 버튼을 누른다 → 비교 리스트에 추가 + 토스트 알림

### Edge Cases
- 카드 정보 로딩 실패 → "정보를 불러올 수 없어요" + 재시도 버튼

---

## Flow 간 연결
| From | To | 트리거 |
|------|----|--------|
| 홈 | 검색 결과 | 필터 설정 후 "카드 찾기" |
| 홈 | AI 추천 결과 | AI 입력 후 "추천받기" |
| 홈 | 카드 상세 | 인기 카드 탭 |
| 검색 결과 | 카드 상세 | 카드 탭 |
| AI 추천 결과 | 카드 상세 | 카드 탭 |
| 검색 결과 | 카드 비교 | 2~3개 선택 후 "비교하기" |
| AI 추천 결과 | 카드 비교 | 2~3개 선택 후 "비교하기" |
| 카드 비교 | 카드 상세 | 카드 탭 |
| 카드 상세 | 이전 화면 | 뒤로가기 |
| 검색 결과 (Empty) | 홈 | "조건 다시 설정" |
| AI 추천 결과 | 검색 결과 | "직접 검색하기" 링크 |
| 검색 결과 | AI 추천 결과 | "AI에게 추천받기" 링크 |
