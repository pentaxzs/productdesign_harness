# Screen Specs

## Screen 목록
```
[홈] → [검색 결과] → [카드 상세]
[홈] → [AI 추천 결과] → [카드 상세]
[검색 결과 / AI 추천 결과] → [카드 비교]
[카드 비교] → [카드 상세]
```

총 5개 화면:
1. 홈
2. 검색 결과
3. AI 추천 결과
4. 카드 비교
5. 카드 상세

---

## Screen 1: 홈

### 목적
AI 추천, 카드 검색, 인기 카드 세 가지 진입점을 모두 보여주는 허브 화면. GNB의 각 메뉴는 결과 페이지로 연결된다.

### 진입 경로
- URL 직접 접근
- 헤더 로고 / "홈" 클릭

### 핵심 정보 (우선순위 순)
1. 서비스 소개 (한 줄 카피: "나에게 맞는 카드, 쉽게 찾자")
2. AI 추천 입력 패널 (텍스트 입력 + 추천받기 버튼)
3. 카드 검색 패널 (카드 종류 탭, 혜택 태그, 카드사 Select, 연회비 Slider, 카드 찾기 버튼)
4. 인기 카드 미리보기 (3~4장)

### 레이아웃
- Mobile: AI 패널 → 검색 패널 → 인기 카드 (세로 스택)
- Desktop: AI 패널 | 검색 패널 (2컬럼) → 인기 카드 (3컬럼 그리드)

### 사용자 액션
- AI 입력 후 "추천받기" 클릭 → AI 추천 결과로 이동
- 필터 설정 후 "카드 찾기" 클릭 → 검색 결과로 이동 (필터 적용 상태)
- 인기 카드 탭 → 카드 상세로 이동

### Primary CTA
"추천받기" / "카드 찾기" (두 패널에 각각 1개)

### 상태
| 상태 | 설명 |
|------|------|
| Default | 필터 미설정, 인기 카드 표시 |

### 이동 경로
- → 검색 결과 ("카드 찾기")
- → AI 추천 결과 ("추천받기")
- → 카드 상세 (인기 카드 탭)

### DS 컴포넌트 후보
- Header — 상단 네비게이션 (로고 + 메뉴)
- Hero Basic — 서비스 소개 카피 + 검색 진입
- Tabs — 신용카드/체크카드 전환
- Tag Toggle Group — 혜택 필터 (캐시백, 마일리지, 할인, 교통, 쇼핑 등)
- Select Field — 카드사 선택
- Slider Field — 연회비 범위
- Button — "카드 찾기" Primary CTA
- Hero Form — AI 추천 입력 영역
- Input Field — AI 질문 입력
- Card Grid Image — 인기 카드 미리보기 (3~4장)
- Credit card — 카드 비주얼
- Footer — 하단 정보

## Screen 2: 검색 결과

### 목적
설정한 조건에 맞는 카드 목록을 보여주고, 카드를 선택하거나 비교할 수 있게 한다.

### 진입 경로
- 홈 → "카드 찾기" 클릭
- AI 추천 결과 → "직접 검색하기" 링크

### 핵심 정보 (우선순위 순)
1. 검색 결과 수 ("32개의 카드를 찾았어요")
2. 적용된 필터 태그 요약 (수정/삭제 가능)
3. 정렬 옵션 (인기순, 연회비 낮은순, 혜택 높은순)
4. 카드 목록 (카드 이미지, 이름, 카드사, 핵심 혜택 3개, 연회비)

### 사용자 액션
- 필터 태그 제거/수정 → 결과 재로딩
- 정렬 변경
- 카드 탭 → 카드 상세로 이동
- 비교 체크박스 선택 (최대 3개) → 하단 비교 바 표시
- "비교하기" 클릭 → 카드 비교로 이동
- "AI에게 추천받기" 링크 → AI 추천으로 전환

### Primary CTA
카드 탭 → 카드 상세 화면

### 상태
| 상태 | 설명 |
|------|------|
| Default | 카드 목록 표시 + 결과 수 + 필터 요약 |
| Empty | "조건에 맞는 카드가 없어요" + 조건 완화 제안 + 인기 카드 3장 |
| Loading | 카드 카드 스켈레톤 (3~4개) |
| Error | "검색 중 오류가 발생했어요" + 재시도 버튼 |

### 이동 경로
- → 카드 상세 (카드 탭)
- → 카드 비교 (비교하기 버튼)
- → AI 추천 결과 ("AI에게 추천받기")
- ← 홈 (뒤로가기 / 헤더 로고)

### DS 컴포넌트 후보
- Header — 상단 네비게이션
- Tag Toggle Group — 적용 필터 표시/수정
- Select Field — 정렬 옵션
- Card Grid Image — 카드 목록
- Credit card — 카드 비주얼 (썸네일)
- Tag — 혜택 태그 ("캐시백 3%", "마일리지 1.5")
- Checkbox Field — 비교 선택 체크박스
- Button — "비교하기" (하단 고정 바)
- Footer — 하단 정보

## Screen 3: AI 추천 결과

### 목적
AI가 사용자의 입력을 분석하여 맞춤 추천한 카드를 순위와 함께 보여준다.

### 진입 경로
- 홈 → "추천받기" 클릭
- 검색 결과 → "AI에게 추천받기" 링크

### 핵심 정보 (우선순위 순)
1. 사용자 입력 요약 ("월 200만원, 온라인 쇼핑 위주")
2. AI 추천 요약 멘트 ("소비 패턴에 맞는 카드 3장을 골랐어요")
3. 추천 카드 목록 (1~5개, 순위 배지 + 추천 이유)
4. 각 카드의 핵심 혜택

### 사용자 액션
- 카드 탭 → 카드 상세로 이동
- 비교 체크박스 선택 → 하단 비교 바 표시
- "비교하기" 클릭 → 카드 비교로 이동
- "다시 추천받기" → 홈 AI 입력으로 돌아가기
- "직접 검색하기" → 검색 결과로 이동

### Primary CTA
카드 탭 → 카드 상세 화면

### 상태
| 상태 | 설명 |
|------|------|
| Default | 추천 카드 목록 + 순위 + 추천 이유 |
| Loading | AI 분석 중 애니메이션 + "맞춤 카드를 찾고 있어요..." (3~5초) |
| Error | "추천을 생성하지 못했어요" + 재시도 / "직접 검색하기" 안내 |

### 이동 경로
- → 카드 상세 (카드 탭)
- → 카드 비교 (비교하기 버튼)
- → 검색 결과 ("직접 검색하기")
- ← 홈 ("다시 추천받기")

### DS 컴포넌트 후보
- Header — 상단 네비게이션
- Card — 추천 카드 (순위 배지 + 추천 이유 텍스트)
- Credit card — 카드 비주얼
- Tag — "1순위", "2순위", 혜택 태그
- Stats Card — AI 분석 요약 ("당신의 소비 패턴")
- Checkbox Field — 비교 선택
- Button — "비교하기" (하단 고정 바)
- Button — "다시 추천받기" Secondary
- Footer — 하단 정보

## Screen 4: 카드 비교

### 목적
선택한 2~3개 카드를 나란히 비교하여 최적의 카드를 결정할 수 있게 한다.

### 진입 경로
- 검색 결과 → "비교하기" 클릭
- AI 추천 결과 → "비교하기" 클릭

### 핵심 정보 (우선순위 순)
1. 카드 이미지 + 이름 + 카드사
2. 연회비 비교
3. 주요 혜택 비교 (항목별 나란히: 캐시백, 마일리지, 할인 등)
4. 전월 실적 조건
5. 부가 서비스 비교

### 사용자 액션
- 비교 항목 스크롤 (모바일: 좌우 스와이프)
- 카드 제거 (X 버튼)
- 카드 이름/이미지 탭 → 카드 상세
- "발급 신청" → 해당 카드사 페이지 (외부)

### Primary CTA
"발급 신청" → 외부 카드사 페이지

### 상태
| 상태 | 설명 |
|------|------|
| Default | 2~3개 카드 비교 테이블 |
| Empty | "비교할 카드를 선택해주세요" + 검색/추천 이동 안내 (카드 모두 제거 시) |

### 이동 경로
- → 카드 상세 (카드 탭)
- → 외부 (발급 신청)
- ← 이전 화면 (뒤로가기)

### DS 컴포넌트 후보
- Header — 상단 네비게이션
- Card Grid Pricing — 비교 테이블 (나란히 배치)
- Credit card — 카드 비주얼
- Button — "발급 신청" Primary CTA (각 카드 하단)
- Icon Button — 카드 제거 (X)
- Tag — 혜택 항목별 값 표시
- Footer — 하단 정보

## Screen 5: 카드 상세

### 목적
선택한 카드의 모든 혜택, 조건, 발급 정보를 상세하게 확인하고 발급을 결정한다.

### 진입 경로
- 검색 결과 → 카드 탭
- AI 추천 결과 → 카드 탭
- 카드 비교 → 카드 탭
- 홈 인기 카드 → 카드 탭

### 핵심 정보 (우선순위 순)
1. 카드 이미지 (대형) + 이름 + 카드사
2. 연회비 (국내/해외)
3. 전월 실적 조건
4. 핵심 혜택 요약 (3~5개, 아이콘 + 텍스트)
5. 상세 혜택 (Accordion: 카테고리별 펼치기/접기)
6. 발급 조건 (신용등급, 소득 등)
7. 유의사항

### 사용자 액션
- 혜택 Accordion 펼치기/접기
- "발급 신청" 클릭 → 외부 카드사 페이지
- "비교에 추가" 클릭 → 비교 리스트에 추가 + 토스트 알림
- 뒤로가기 → 이전 화면

### Primary CTA
"발급 신청" → 외부 카드사 페이지 (하단 고정)

### 상태
| 상태 | 설명 |
|------|------|
| Default | 카드 상세 정보 전체 표시 |
| Loading | 콘텐츠 스켈레톤 (카드 이미지 + 텍스트 블록) |
| Error | "정보를 불러올 수 없어요" + 재시도 버튼 |

### 이동 경로
- → 외부 (발급 신청)
- → 카드 비교 (비교에 추가 후 비교하기)
- ← 이전 화면 (뒤로가기)

### DS 컴포넌트 후보
- Header — 상단 네비게이션
- Credit card — 카드 비주얼 (대형, 상단)
- Product Info Card — 기본 정보 (연회비, 전월 실적)
- Tag — 혜택 태그
- Card Grid Icon — 핵심 혜택 요약 (아이콘 + 텍스트)
- Accordion / Accordion Item — 상세 혜택 (카테고리별)
- Stats Card — 연회비, 전월 실적 수치
- Button — "발급 신청" Primary CTA (하단 고정)
- Button — "비교에 추가" Secondary
- Footer — 하단 정보
